# Custom phone background

Drop your image in **this folder** named exactly:

```
phone-bg.jpg
```

(`phone-bg.png`, `phone-bg.jpeg`, or `phone-bg.webp` also work.)

That's it — the phone interface (`/` join page and `/play` controller)
automatically picks it up as its full-screen background the next time you
reload. A subtle dark scrim is layered over it so buttons and text stay
readable. No other files need to change.

Tips:
- Portrait orientation looks best (it fills the whole phone screen).
- Keep it under ~500 KB so phones load instantly.
- To go back to the default look, just delete the file.
