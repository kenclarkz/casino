# Background music

Drop your theme song in this folder as `theme.mp3` and it will start looping
on the TV automatically the moment the host presses **START THE SHOW**, and
stop when the show finishes.

`.ogg`, `.wav` and `.m4a` are also supported — name the file `theme.ogg`,
`theme.wav` or `theme.m4a`. With no file here the game stays silent (all other
sound effects are generated in code and always work).
